# Sheaf

Sheaf is being organized as a command hub for many projects.

Start with [structure/README.md](structure/README.md). The `structure/` directory documents the intended repository layout, project rules, configuration model, service registry, logging and data paths, documentation structure, and glossary.

The current code has not been migrated. Existing top-level directories such as `apps/`, `docs/`, `quests/`, and `prompts/` remain in place until a dedicated migration moves projects under `projects/`.

Homebrew installs tools under `/opt/homebrew` on this machine, so local commands and docs should account for that path when referencing Homebrew-managed binaries.
