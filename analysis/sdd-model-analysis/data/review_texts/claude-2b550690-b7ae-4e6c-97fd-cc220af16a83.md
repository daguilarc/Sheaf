### Spec Compliance
- ✅ Spec compliant — the previously Important issue is fixed.

The prior finding was that the storage gate was inert on the raw `WebAssembly.instantiate` path: `sheath_browser_create` could run even when no IDBFS Module existed. In the diff under review:

- The old unconditional call `instance.exports?.sheath_browser_create?.(0, 0)` is removed (boot.js, previously ~line 377).
- Engine creation now sits behind `requireBrowserStorageModule(storageModule)` (boot.js:301–307, 380–384), which throws `"Storage Module unavailable: IDBFS storage is required before startup"`, calls `setStatus(error.message)`, and re-throws — aborting startup before any create call.
- `sheath_browser_create` is only reached via `callBrowserHost(...)` after the require + `mountBrowserStorage` + `await syncBrowserStorage(populate=true)` block (boot.js:386–405).
- Regression test `startBrowserSynth fails before creating host when storage Module is unavailable` (boot.test.mjs) sets `globalThis.Module = undefined`, asserts the promise rejects with `/Storage Module unavailable/`, asserts the `sheath_browser_create` export was never invoked, and asserts the visible status text matches. This directly exercises the raw-wasm-no-Module path.

`hasBrowserStorageModule` (boot.js:291–299) correctly short-circuits on `undefined` Module and requires `FS.mkdir`, `FS.mount`, `IDBFS`, and `syncfs`, so a partially-shaped object cannot slip through the gate.

### Strengths
- The gate is enforced at the single create call site; there is no longer a bypass path, so the fix is structural rather than additive.
- Red-test evidence is credible and the new test asserts the three things that matter: rejection, no `sheath_browser_create`, and a visible status message.
- Post-write sync (`syncBrowserStorageAfterWrite`) is driven from `node.port.onmessage` (main thread), satisfying the "outside the AudioWorklet realtime callback" constraint.
- Failure path acks correctly: `sheath_browser_storage_sync_finished(0)` on populate failure with a visible `Storage sync failed:` status before re-throwing.
