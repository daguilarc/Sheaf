Verdict: **PASS** — no Critical or Important issues. The commit faithfully implements plan Task 1 and OpenSpec `sar-25`.

### Focus-area findings

**Owner-thread enforcement** ✅ — `ownerThread_` captured at construction; `Register`/`ProcessUiFrame` throw `std::logic_error` on wrong thread (`RequireOwnerThread`), while `~Registry`, `Unregister`, and `Size` `assert` (correct split per design: throw where failure is reportable, assert on `noexcept` paths). Wrong-thread test covers both Register and dispatch (`ui_frame_processing_tests.cpp:129`).

**RAII move/destruction safety** ✅ — `Registration` is move-only, uses `std::exchange` so moved-from is inert, `Reset()` is idempotent and null-guarded, move-assign `Reset()`s the target first. `static_assert`s pin non-copyable + nothrow-movable (`:165`).

**Mutation during dispatch** ✅ — `DispatchGuard` sets/clears `dispatching_` (RAII, survives an unexpected callback exit); `Register` during dispatch throws; test confirms registry unchanged (`:127`). Removal during dispatch is assert-guarded, matching the design's "reject or assert" contract.

**Allocation-free dispatch** ✅ — dispatch iterates the existing `std::vector` by range-for (no copy, no growth); test overrides global `operator new` and snapshots an atomic counter around `ProcessUiFrame()` (`:198`).

**Engine/AppContext lifetime & order** ✅ — `uiFrameProcessors_` declared before `context_`/`app_` (`Engine.hpp:842`), so reverse-destruction frees app-owned registrations before the registry; the registry dtor's `assert(processors_.empty())` actively verifies this (asserts are live — `-O2`, no `-DNDEBUG`). Pointer published in the constructor (`Engine.hpp:85`) before `app_.Init` (`:127`); `sawRegistryDuringInit` test confirms non-null pre-Init.

**Exact end-of-tick dispatch** ✅ — `ProcessUiFrame()` is the last statement of `MessageThreadTick()`, after patch/arena/MIDI-output work (`Engine.hpp:838`). Engine test asserts 1 tick → 1 call, 2 → 2.

**Covered-page tree suppression** ✅ — `BuildTree()` builds/validates the app surface only on the Application page (`RuntimeMainComponent.hpp:94`); `TestCoveredRuntimePageDoesNotBuildApplicationTree` pins `buildCount == 1` after switching to a covered page.

**Compatibility** ✅ — no behavioral change to existing surfaces; Makefile dependency edits correctly propagate the new `AppContext.hpp` include to all dependents; new binary wired into `test` with `-pthread` and `BUILD_SENTINEL` order-only prereq.
