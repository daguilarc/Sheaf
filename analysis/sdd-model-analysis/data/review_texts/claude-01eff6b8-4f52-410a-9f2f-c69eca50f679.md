- **projects/synth/include/synth/ButtonGrid.hpp:101-104** — The convenience `StateCell` constructor delegates as `StateCell(offColor, onColor, onColor, offColor, state, FlashPolicy{}, ...)`, which passes `onColor` as `offFlashColor_` and `offColor` as `onFlashColor_` — the flash colors are swapped relative to the base colors. If a future `FlashPolicy` type is both default-constructible and used through this shorthand constructor, cells would show inverted on/off colors while flashing. Fix: swap the argument order to `(offColor, onColor, offColor, onColor, ...)` so flash colors default to the same palette as the non-flash colors.
