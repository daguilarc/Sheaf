### Issues

**Minor**

- `main.ts` (`installSynthBrowserApp` catch + `launchCatalogApplication` catch): on an install failure where the app was constructed, `materialized.dispose()` and `activationLease.dispose()` each run twice (once via `app.stop()` → `disposeModule`/`activationLease.dispose`, once via the outer catch). It is safe today only because every dispose is idempotent. This is defensible defense-in-depth, but the redundancy is worth a one-line comment so a future non-idempotent `dispose` doesn't silently double-fire. No fix required.
