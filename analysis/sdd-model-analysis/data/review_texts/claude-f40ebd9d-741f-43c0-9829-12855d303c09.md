## Minor / Robustness

**3. Cross-file ordering relies on gate *plus* incidental filename order.** `miniapp-smoke.spec.ts:3-20` blocks in `beforeAll` up to 20s for the fake-app gate file. This is robust with ≥2 workers (fake-app writes on worker A while B waits). With `workers=1` (common on 2-CPU CI, where Playwright default is `floor(cpu/2)=1`), the gate cannot be satisfied within the same worker — safety then depends entirely on alphabetical file order (`fake-app` < `miniapp`), which currently holds. If the fake-app file were ever renamed to sort after `miniapp-smoke`, a single-worker run would 20s-timeout-fail instead of ordering correctly. The Make path (`browser-miniapp-smoke: browser-fake-app-test` + `SYNTH_BROWSER_FAKE_GATE_CONFIRMED=1`, Makefile:26-28) is deterministic and not affected.
