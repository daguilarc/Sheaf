# Final Whole-Branch Review — `restore-encoder-mouse-interaction`

## Findings (ordered by severity)

No blocking (high/critical) findings. The branch is a faithful, well-tested restoration. Items below are minor/advisory.

### Minor

**M1 — Test coverage gap: sub-threshold drag and non-interactive draw isolation are unverified.**
The most load-bearing correctness claim of this change — that adding `case Draw: return true` to `IsRenderableKind` (`PortableJuceBackend.hpp:714`) does *not* turn every draw node (scopes, waveforms) into a mouse-intercepting overlay — is guarded only by `IsInteractiveDrawNode` in `CollectRenderableDescendants` (`PortableJuceBackend.hpp:680-683`). I traced this by reading: non-interactive `Draw` nodes take the `if (kind == Draw)` branch and are never added to `m_renderedNodeIds`, so the global `return true` is only reachable for interactive draws. The logic is correct, but there is **no regression test** asserting a plain `Draw` node gets no overlay. Likewise nothing tests that a sub-threshold drag (`|delta| < 0.001`) is ignored. Both are cheap to add and would lock in the two behaviors most likely to silently regress later.

**M2 — Dead-in-practice branch in `DispatchCurrentNodePointerDragAction` (`PortableJuceBackend.hpp:504-529`).**
The colon-free value path (`dispatched.value = deltaValue`) can only be hit by the synthetic `PortableJuceBackendTests` case (value `"stale"`). In the real miniapp, values always carry `slot:pos:delta`, and if a colon-free value ever reached `ParseEncoderGestureValue` it would be *rejected* (no message dispatched). So the test exercises a code path whose output the real parser would discard — it validates the substitution mechanics but not a reachable end-to-end behavior. Harmless, but worth a comment noting the branch exists only for the generic-overlay contract, not encoders.

### Nits

**N1 — Hardcoded slot `0` as a bare literal.** `MiniAppUI.hpp:894,898` call `FormatEncoderGestureValue(0, ix, 0.0f)`. This is *correct* — the miniapp only renders `slots[0]` (`MiniAppUI.hpp:65`), matching the original `EncoderComponent` binding — but the `0` is a magic literal duplicated twice. A named constant would document the single-slot coupling.

**N2 — Double threshold guard.** `|delta| < 0.001` is checked both in the JUCE overlay (`mouseDrag`) and again in `DispatchMiniAppAction`. This is intentional defense-in-depth (the model must stay correct independent of backend), not a bug — noting only so it isn't "cleaned up" later.
