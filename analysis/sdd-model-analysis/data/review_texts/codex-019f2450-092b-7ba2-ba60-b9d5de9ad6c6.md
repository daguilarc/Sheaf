### Spec Compliance
Compliant. The patch label reads `CurrentPatchDirectory()` during `RepaintAll()` each repaint tick, uses the directory filename or `"(no patch)"`, and stays on the message-side shell/runtime path. Save with no current patch reuses `LaunchSaveAsChooser()` directly, with `Runtime::SavePatch()`/`LogPatchCommand()` unchanged as the `NeedsSaveAsPath` backstop. README notes are present in both required files.

### Strengths
- Save fallback uses the exact existing Save As helper, avoiding duplicated chooser logic.
- The label refresh happens after `MessageThreadTick()` via the repaint hook, so async save/load state changes are visible on the next UI tick.
- No audio-side access or alternate identity cache was introduced.
