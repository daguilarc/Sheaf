## Concurrency / correctness audit (independently verified)

- **Publication protocol / ABA-reuse safety** — Sound. Tags encode the *full* 64-bit sequence (`CompleteTag = 2·S+2`, in-progress `2·S+1`), so a slot's tag equals a given `expectedTag` for exactly one logical sequence; sequences sharing a physical slot differ by `capacity` and therefore have distinct tags. No ABA within the 64-bit space.
- **Memory ordering** — Sound. Producer does seq_cst in-progress → seq_cst payload → seq_cst complete, then release-publishes the count; consumer acquire-loads the count, then seq_cst before-tag → seq_cst payload → seq_cst after-tag. The single seq_cst total order guarantees a payload accepted with `before == after == expectedTag` is the one written for that sequence (the reused write's in-progress store `2·S'+1 ≠ expectedTag` must fall outside the bracket). Payload is `std::atomic<float>`, so even a rejected read is fully defined — no data race. TSAN clean over 200k reused slots corroborates.
- **Publish→consume visibility** — release/acquire on `publishedSamples_` establishes happens-before from each complete-tag store to the consumer's tag loads for sequences within the snapshot; later overwrites are caught by the bracket.
- **Bounded attempts under sustained producer** — Confirmed. One `published` snapshot per call; fast-forward can trigger at most once (afterward `published − next == capacity`); every remaining iteration either accepts (`consumed++`) or breaks. `lastConsumeAttempts_ ≤ maxSamples`. This is the fix for the prior "unbounded retry" Important issue, and `LastConsumeAttemptsForTesting() <= 3`/`== 0` assertions pin it.
- **Gap / overwrite accounting** — Correct. `overwrittenSamples_ += (published−capacity) − next` on skip, `nextConsumerSequence_` advanced to `published−capacity`; the `next == consumed + overwritten` invariant is preserved and drives the deterministic overflow test (retains newest 4 of 10, counts 6) and the stress-test sequence derivation `consumed+overwritten−1`. No double counting across calls; no `published − next` underflow (guarded and invariantly `next ≤ published`).
- **Newest-capacity retention/order** — Correct; the oldest retained slot is inherently contended with the producer's next reuse, but the bracket rejects it gracefully and the next call re-fast-forwards. Correctness preserved (efficiency-only edge).
- **Reset concurrent with Writer** — Safe. `Reset` touches only consumer-owned state and *reads* `publishedSamples_` with acquire; it never mutates `producerSequence_`, tags, payloads, or the publication store. This is the fix for the prior "Reset races producer state" Important issue.
- **Phase invalidation before first post-gap sample** — `InvalidatePhase()` runs inside the fast-forward branch before any retained sample is `AddSample`'d; test confirms `PhaseBaseForTesting() == 0.0` post-gap and reacquisition afterward.
- **Tag/sequence overflow** — `kMaximumSequence = (2⁶⁴−3)/2` with a pre-store `> kMaximumSequence → std::terminate()` guard; the last valid `CompleteTag` is exactly `2⁶⁴−1`, no UB. Consumer tag arithmetic bounded by the same. `std::terminate` is not an exception, so the noexcept/no-throw Writer contract holds (≈1.5M years at 192 kHz).
- **CreateReader budget** — `ConsumePending(config_.consumeBudget)` before `Analyze`; budgeted-drain test confirms 3→3→1 with budget 3.
- **Lock-free requirement** — Constructor validates `is_lock_free()` on the publication counter and every payload/tag slot, throwing before any Writer use ("rejected before DSP processing begins").
- **Writer realtime contract** — `Push` overloads are `noexcept` (static_assert-pinned) and do only bounded atomic stores/iteration: no allocation, lock, wait, exception, FIR/YIN/refinement.
