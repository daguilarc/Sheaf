Timestamping uses one `steady_clock` epoch for both the engine provider and callback timestamps. Destructor ordering removes the callback and stops the timer before `engine_` destruction. The audio wrapper itself is bounded: TLS tag, stack `AudioBlock`, timestamp read, engine call.
