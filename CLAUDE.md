# Project Instructions

## Agents, Roles, and Skills

When the user assigns you a role, read the following to understand what to do:

1. `agents/README.md` — layout of the agents directory
2. `agents/roles.md` — summary of all role boundaries
3. `agents/roles/<role>/ROLE.md` — detailed rules for the assigned role

Skills (tool-facing definitions used by editor integrations) are in `agents/skills/<name>/SKILL.md`.

## Workflow

Quest-based workflow docs that roles depend on:

- `docs/workflow/README.md` — overview and quest structure
- `docs/workflow/stages.md` — stage definitions and change controls
- `docs/workflow/quests.md` — shared quest file rules
- `docs/workflow/issues.md` — issue tracking format

Active quests live under `workflows/main_quests/` and `workflows/side_quests/`.
